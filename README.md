# The Age of Dragons

[Português](README.pt-BR.md) · English

An interactive, scroll-driven "documentary" about dragons in mythology and pop culture. A WebGL act opens the page (a dragon revealed from the dark, advancing and breathing fire as you scroll), followed by chapters on the world's dragon mythologies, a map of where the legends were born, and a timeline of dragons on screen. The site content is in Brazilian Portuguese.

## Features

- **Act I (scroll-scrubbed):** frame sequences (`public/dragao/{revelacao,avanco,fogo}`) drawn on a single WebGL canvas, with a 640px variant for small screens and a tiny inline poster shown before JavaScript loads.
- **Procedural ember/lava background** rendered with React Three Fiber and post-processing, sharing the same canvas as Act I.
- **Smooth scroll** with Lenis driven by the GSAP ticker; scroll state is bridged to Three.js without React re-renders (`src/scene/scroll-store.ts`).
- **Chapter I – "O nascimento":** dragon traditions (Chinese, Japanese, medieval European, biblical, Norse, Mesoamerican and Celtic) illustrated with historical artworks.
- **Chapter II – "O mapa":** interactive world map with markers for each tradition.
- **Chapter III – "As telas":** timeline of dragons in film and TV.
- Chapter navigation and progress indicator, share call-to-action, SEO metadata, Open Graph image, `robots.txt`, `sitemap.xml` and web manifest.
- Extra researched content (fiction dragons, comparison table, curiosities, gallery) kept in `src/data/` and `src/components/sections/` for a future archive page; it is not rendered on the home page.
- `/laboratorio`: an isolated test bench for Act I with a debug HUD (`noindex`).

## Getting started

Prerequisites: Node.js 20.9+ (CI uses Node 22) and pnpm 10.

```bash
pnpm install --frozen-lockfile
pnpm dev          # http://localhost:3000
```

No environment variables are required.

## Project structure

```
src/
  app/          # layout, home page, /laboratorio, robots, sitemap, manifest
  scene/        # WebGL stage, Act I, frame-sequence reveal, ambient background, scroll store
  motion/       # Lenis smooth scroll and scroll-driven effects
  components/   # chapter navigation/plates, sections, icons
  data/         # chapter content (eras, map, cinema timeline, archive data)
public/
  art/          # historical artworks and concept art used in the chapters
  dragao/       # Act I frame sequences (+ /sm small variants) and chapter plates
  og.jpg        # social card
```

- **Concept art** `dragao-biblia.webp` and `devorador.webp` are AI-generated images supplied by the author.
- An older version used a hero video (`public/video/dragao-scrub.mp4`), removed from the current code; its origin is not documented.
- Fonts: Cinzel, Cormorant Garamond and Inter via `next/font/google`.

## Limitations

- The experience relies on WebGL and about 16 MB of image assets (frame sequences); it is heavier on low-end devices and slow connections.
- Content is only available in Portuguese.
- There are no automated tests; checks are lint, type-check and build.
